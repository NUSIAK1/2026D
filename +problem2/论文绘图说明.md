# 问题二论文绘图

绘图入口为 `problem2.plotProblem2Paper()`。在 MATLAB 中将工作目录切换到 `代码/`，执行：

```matlab
files = problem2.plotProblem2Paper();
```

程序读取 `结果/问题二_绘图配置.xlsx` 的 `绘图设置` 工作表：

- `B2` 选择代表方案，默认 `TimelinessFirst`（及时性优先）。其他可选值见表内下方列表。
- `B3` 填写 `结果/` 目录下的分析表文件名，默认 `问题二_多目标调度分析.xlsx`。

修改 Excel 后重新运行同一条 MATLAB 命令，即可重绘七张图，无需修改程序。PNG（400 dpi）和矢量 PDF 均输出到 `论文/图表/问题二/`，同名文件会更新。图内不加图题，论文排版时可另写图注。问题二求解器不再自动生成原先的低分辨率图；求解结果更新后请单独运行此绘图入口。

数据使用 `代表方案架次`、`代表方案逐箱交付`、`Pareto前沿`、`代表方案汇总` 工作表，地形来自原始 DEM MAT 文件。程序会校核货箱编号唯一、逐箱记录与架次关联，以及总能耗和完成时间与汇总表一致。

时限矩阵对医疗与首批保障货箱使用硬截止时间，对其余货箱使用期望时间；负数表示超过相应时间。格内 `W/F/M/H` 分别表示饮用水、应急食品、医疗物资、卫生用品。电池 SOC 图的返航 SOC 与充电结束时间来自分析表，90% 节点按题目两阶段充电规则计算。飞行时段以虚线连接起飞和返航事件，仅用于说明事件顺序，不表示逐秒 SOC 的精确轨迹。电池甘特图中彩色条为执行架次，灰色条为充电；最后一个架次后也显示完整充电过程。两张图中的紫色竖直点线为所有运输机最后返航的时刻，其右侧的充电发生于任务完成后。

原 `Plot_q2.py` 保留为单独绘制无人机甘特图的 Python 入口，现也读取同一个 Excel 方案选择并保存到同一论文图表目录。论文全套图片以 MATLAB 入口输出的七张图为准。
